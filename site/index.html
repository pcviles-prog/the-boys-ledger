About this tracker
Static site. No server. Your data stays as files.

This page reads site/data/cards.json (exported from your Excel file) and builds a searchable checklist. It’s designed to be hosted on GitHub Pages or just opened locally.

  • To update data: run python scripts/export_from_excel.py and re-deploy.
  • To add images: put .jpg files into site/images/ named by the card id shown in the detail view.

Tip: keep a “public” export with ownership fields removed if you don’t want the world to see your progress.
